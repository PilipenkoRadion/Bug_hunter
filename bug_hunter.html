🐜 FEHLER-JÄGER AKADEMIE

Interaktive Lernplattform für Programmierung — Technischer Stack

📋 Projektübersicht

Fehler-Jäger Akademie ist eine Bildungsplattform, die Benutzer zum Programmierenlernen durch interaktive Spiele hilft. Zwei verschiedene Editionen konzentrieren sich auf unterschiedliche Programmiereraspekte:

🐍 Python Edition: Debugging-Praxis — Fehler finden, toten Code entfernen, Logik wiederherstellen

🎨 CSS Edition: Interaktives CSS-Lernen — Positionierung, Transformationen, Effekte

⏱️ Zwei Modi: Timer-Modus (schnell) mit Rangliste oder Casual-Modus (stressfreies Lernen)

🎨 Frontend (React 18 + CSS)

Technologie Zweck Besonderheiten
React 18 UI-Framework Hooks (useState, useEffect, useRef), funktionale Komponenten, State-Management
Babel JSX-Transpiler JSX-zu-JavaScript-Transformation direkt im Browser
Custom CSS Styling Kustom CSS-Variablen, Responsive Design, animierte Übergänge
Vanilla JS Interaktivität Fetch API für HTTP-Anfragen, Timer-Management, Antwort-Validierung
HTML5 Canvas Konfetti-Animation Konfetti-Effekt bei richtigen Antworten

React-Komponenten:

Komponente Funktion State
NameModeScreen Spiel- und Moduswahl (Timer/Casual) name, mode, game (python | css)
PythonGame Python Edition mit 10 Levels currentLevel, score, gameState, timeLeft, showHint
CssGame CSS Edition mit interaktiver Demo-Box currentLevel, score, userAnswer, feedback, timeLeft
Leaderboard Rangliste mit Spielfilterung scores (aus API), filter (all | python | css)
StatsOverlay Endstatistik (5 Sekunden) stats, rank, countdown, onClose
TimerRing Visueller Timer mit Fortschritt seconds, maxSeconds, Farbübergänge

⚙️ Backend (Flask + Python)

Komponente Technologie Funktion
Flask Web-Framework Erstellung von REST API und Servierung statischer Dateien
Flask-CORS Sicherheit CORS-Richtlinie für Cross-Domain-Anfragen vom Frontend
JSON Storage Persistente Speicherung Ergebnisse in scores.json speichern
Python 3.8+ Runtime Hauptprogrammiersprache des Servers

Server-Struktur:

server.py ├── load_scores() → JSON-Ergebnisse lesen ├── save_scores() → Neue Ergebnisse speichern │ └── Routes: ├── GET / → HTML-Seite mit Rangliste ├── GET /game → bug_hunter.html senden ├── GET /api/scores → Top-20 abrufen ├── POST /api/scores → Neues Ergebnis hinzufügen └── DELETE /api/scores → Alles löschen (nur Test)

🎮 Zwei Spiel-Editionen

🐍 Python Edition (10 Level)

Typ Beschreibung Beispiele
🔧 Fix (3 Level) Syntaxfehler korrigieren Klammern hinzufügen, Fehler beheben, Einrückung korrigieren
🔍 Finde (4 Level) Toten Code finden (ungenutzte Variablen) Welche Variable wird erstellt aber nicht verwendet?
📝 Ordne (3 Level) Richtige Code-Reihenfolge wiederherstellen Funktion, Schleife oder Bedingung aus durcheinander geratenen Zeilen zusammensetzen

📊 Punktesystem

• 100 Punkte = ohne Tipps
• 50 Punkte = mit Tipp
• 0 Punkte = Antwort gezeigt

🔄 Systemarchitektur

Browser (React 18 + Babel) ↓ Fetch API (JSON) ├─ POST /api/scores (neues Ergebnis) ├─ GET /api/scores (Rangliste abrufen) └─ DELETE /api/scores (nur zum Testen) ↓ Flask Server (Python) ├─ CORS Middleware (Cross-Domain-Anfragen erlauben) │ └─ Routes: ├─ GET / → Ranglisten-HTML ├─ GET /game → bug_hunter.html (React App) │ └─ REST API (/api/scores): ├─ GET → Top-20 Spieler ├─ POST → Ergebnis speichern │ {name, game, mode, score, percent, avg_time} └─ DELETE → scores.json löschen ↓ scores.json └─ JSON-Array aller Ergebnisse (Persistente Speicherung auf Server)

Datenfluss in React:

App Component ├─ screen = 'menu' | 'python' | 'css' | 'leaderboard' ├─ playerName (String) ├─ timerMode (Boolean) │ └─ handleStart({ game, name, timerMode }) ├─ Wechselt Bildschirm ├─ Speichert playerName & timerMode └─ Übergibt an Spiel-Komponente PythonGame / CssGame ├─ currentLevel = 0..9 ├─ score (akkumuliert) ├─ gameState = 'menu' | 'playing' | 'levelComplete' | 'completed' ├─ timeLeft (von TIMER_MAX bis 0) ├─ showStats = true (5 Sek => Endstatistik) │ └─ Bei Spielende: 1. POST /api/scores mit finalen Daten 2. rank & total abrufen (Platzierung) 3. StatsOverlay 5 Sekunden anzeigen 4. Zu 'completed' Bildschirm wechseln

📡 API Endpoints

GET /api/scores
Top-20 Ergebnisse abrufen

curl http://localhost:5000/api/scores

Antwort:
[
  {
    "name": "Alice",
    "game": "python",
    "score": 850,
    "percent": 85.0,
    "avg_time": 42.3,
    "timestamp": 1710000000
  },
  ...
]
POST /api/scores
Neues Ergebnis speichern und Platzierung abrufen

curl -X POST -H "Content-Type: application/json" \
  -d '{"name":"Bob","game":"css","score":900}' \
  http://localhost:5000/api/scores

Request Body:
{
  "name": string (erforderlich),
  "game": "python" | "css",
  "mode": "timer" | "casual",
  "score": Zahl,
  "max_score": Zahl,
  "percent": Zahl (wird automatisch berechnet),
  "avg_time": Zahl,
  "total_time": Zahl
}

Antwort:
{
  "ok": true,
  "rank": 5,
  "total": 42
}
DELETE /api/scores
Alle Ergebnisse löschen (nur zum Testen)

curl -X DELETE http://localhost:5000/api/scores

📊 Technische Spezifikationen

⏱️ Timer

• Max. Zeit: 180 Sekunden (3 Min)
• Fortschrittsbalken mit Farbindikation
• Pulsierender Effekt bei <10 Sekunden

🎮 Modi

• Timer-Modus: mit Rangliste
• Casual-Modus: stressfreies Lernen
• Beide Modi haben gleiche Level

📚 Level

• Python: 10 zufällige aus 16 Pool
• CSS: 10 zufällige aus 16 Pool
• shuffle() für Variabilität

🏆 Rangliste

• Top-20 beste Ergebnisse
• Sortierung nach Score DESC, Zeit ASC
• Filter nach Spiel (Python/CSS)

💾 Speicherung

• JSON-Datei (scores.json)
• UTF-8 Kodierung
• Auto-Speicherung nach jedem Ergebnis

🎨 UI-Framework

• React 18 (CDN Babel)
• Custom CSS (nicht Bootstrap)
• Responsive Design (mobil-freundlich)
